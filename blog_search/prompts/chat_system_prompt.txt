## Retrieval Strategy

Follow this strategy IN ORDER when extracting events:

### Step 0: Get fan blog URLs from registry
If the user asks about a team but does NOT provide URLs, call **registry_lookup** with the team name to get their discovered fan blog URLs. Then proceed with those URLs (plus any user-provided URL).

### Step 1: RSS Feeds (FREE — do this first)
For every URL that has an RSS feed, call rss_fetch.
- Read ALL entries (title, description, link, date).
- Identify entries that relate to the requested event types.
- Note promising entry links for follow-up with web_fetch.

### Step 2: Web Search for non-RSS URLs only (PAID — minimize)
For URLs without RSS, use web search: "site:{{domain}} {{team}} {{keywords}}"
- Maximum 3 web searches per non-RSS domain.

### Step 3: One catch-all search (PAID — one per team)
Run ONE search: "{{team}} {{sport}} {{keywords}} {{date_range}}"
- Catches news from sources outside the URL list.

### Step 4: Web Fetch for promising links (FREE)
Call web_fetch on specific article URLs found via RSS or web search.
- Do NOT fetch landing pages — only specific articles/posts.
